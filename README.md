# Vidious Cycle

Yet another YouTube-to-Invidious redirect userscript.

The world did not need another one of these, which is unfortunate, because here it is.

This script redirects YouTube video URLs to a user-selected Invidious instance. The twist, if we are being generous with the word “twist”, is that the instance picker only shows monitored HTTPS instances currently reported as online. It does not randomly yeet you across the internet, because randomness is not resilience, it is just entropy with branding.

Built because I wanted a script that was readable, unsurprising, and not held together by seven nested preferences panels and the faint smell of 2014.
